# Om Prakash Muduli — Creative Web Developer Portfolio

A modern, high-performance, and editorial web developer portfolio showcasing full-stack projects, real-time AI applications, 3D spatial web experiences, and an interactive scroll-driven canvas storytelling engine.

## 🌟 Features & Highlights

- **Warm Coffee & Mocha Palette:** Sophisticated lighting environment (`#D8C3A5`, `#C5A98A`, `#1C1510`) with subtle rose-lilac ambient accents and film grain.
- **Interactive Cursor Spotlight:** Dual-layer day/night background reveal effect that smoothly follows cursor movement.
- **Canvas Scroll-Driven Storytelling Engine:** 60 FPS HTML Canvas frame sequence with smooth lerped transforms across 3 chapters:
  1. **About Me** (150 frames)
  2. **Skills Arsenal** (100 frames)
  3. **Work Experience & Awards** (299 frames)
- **Project Discovery Archive:**
  - **Evelyn AI Assistant:** Windows-based personal AI assistant (★ 1st Position Winner at Annual Tech Fest IDEAS 2K25).
  - **DevClash / BuildClash:** Freelance marketplace and developer coding challenge arena with escrow and sandboxes.
  - **GestureCraft 3D:** Webcam-based 21-point spatial hand tracking for 3D object manipulation using Three.js and MediaPipe.
  - **Team Task Manager:** Full-stack collaborative task management application built with Next.js and Supabase.
- **Integrated Resume & Inquiry Dialog:** One-click PDF resume preview/download and direct contact options.
- **Responsive Magazine Colophon:** Tactile icon dock for social networks, section navigation, and tech capability chips.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+), HTML Canvas API
- **Creative & 3D:** Three.js, MediaPipe, WebGL
- **Styling:** Custom CSS Custom Properties, Fluid Clamp Typography, Glassmorphism, Micro-interactions
- **Backend / Tools:** Python, Node.js, Git, Vite

## 🚀 Getting Started

### Direct Preview
Open `index.html` in any modern web browser.

### Local Development Server
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve .
```
Then navigate to `http://localhost:3000` in your browser.
